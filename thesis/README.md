# LMS LaTeX Template
The LaTex template for bachelor/master thesis reports is contained in the folder 'thesis'.

The template is currently only availale in German. Feedback regarding adaptations for English reports are appreciated.

## Useful information
Please consider the following useful documents when preparing your thesis:

- [General hints for citations in scientific writing](AllgemeineHinweiseZitieren/RichtigZitieren.pdf) (currently only in German)
