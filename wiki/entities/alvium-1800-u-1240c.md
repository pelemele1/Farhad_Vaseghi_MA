# Alvium 1800 U-1240c

The camera used for this thesis's data-collection rig ([[data-collection-rig]]).
Confirmed as the exact connected unit in an earlier session via Vimba X
Viewer: serial `1800 U-1240c-05HYK (DEV_1AB22C03EA2C)`. Two of these are
mounted side by side on the rig (left/right lens pair).

| Sensor model | Sony IMX226 |
| Resolution | 4024 (H) × 3036 (V); 12.2 MP |

| Shutter type | Rolling shutter (RS) or Global reset shutter (GRS) |

## Focal length vs. field of view (guide Table 134, p. 267)

Type 1/1.7 sensor (9.33 mm diagonal). FOV given as H × V in mm, at two
object distances:

| Focal length [mm] | FOV @ 500 mm object distance | FOV @ 1000 mm object distance |
|---|---|---|
| 4.8 | 609 × 461 | 1226 × 928 |
| 6 | 455 × 344 | 918 × 694 |
| 8 | 301 × 228 | 609 × 461 |
| 12 | 224 × 169 | 455 × 344 |
| 16 | 141 × 106 | 289 × 218 |
| 25 | 98 × 74 | 204 × 154 |
| 50 | 67 × 50 | 141 × 106 |

Note: the table in the source PDF had one row above 4.8 mm whose focal
length value wasn't captured cleanly by text extraction (FOV values
763 × 578 / 1534 × 1161 at an unconfirmed focal length, possibly 3.5 mm or
4 mm) — don't rely on that row without checking the actual PDF page.
`docs/data_collection_pipeline.md`'s equipment table already extrapolates
this same table out to the 10–20 m object distances actually relevant for
this thesis's rig (parked-car/street scenes); this page is the raw
manufacturer numbers it was built from.
